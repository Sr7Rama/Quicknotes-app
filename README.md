# QuickNotes App

QuickNotes is a clean, lightweight note-taking web application that lets users quickly capture, organize, and search their thoughts across custom categories.

## Features

- **Category Organization:** Tag notes as Personal, Work, or Study with visual border indicators.
- **Form Validation:** Prevents empty submissions and limits notes to 200 characters.
- **Real-Time Search:** Instantly filter notes by keyword as you type.
- **Data Persistence:** Automatically stores notes in browser `localStorage`.
- **Responsive Layout:** Flexbox form and layout adapted for desktop and mobile viewports.
- **Clear All Option:** Reset all stored notes with a single click and confirmation safety dialog.

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Sr7Rama/Quicknotes-app.git
   ```
2. Open `index.html` in a web browser.
